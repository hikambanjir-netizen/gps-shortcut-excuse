The GPS's one-line excuse for sending the driver down the wrong road:

> Technically the road exists. It just ends at a lake, a wedding, and a very angry father of the bride.

`main.py` (Python 3.13, standard library only) writes that single line to `/output/entry.txt` — 101 characters, one line of plain text, no setup and no dialogue tags, just the excuse itself, in the GPS's own smug, defensive voice.

## Run it

```sh
python3 main.py
```
